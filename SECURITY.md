# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: on this repository's **Security** tab, choose
**Report a vulnerability**
([direct link](https://github.com/triptechtravel/sequin/security/advisories/new)).
The report is only visible to you and the maintainers.

A useful report includes:

- what is affected and how severe it is
- steps or a minimal proof of concept to reproduce it
- the version or tag you tested (e.g. `v0.14.6-tt12`)
- a suggested fix, if you have one

We aim to acknowledge reports within a few working days and will keep you updated
in the advisory until a fix is released. We are happy to credit you in the
advisory and the [CHANGELOG](CHANGELOG.md) unless you would rather stay anonymous.

## Supported versions

Only the latest `v0.14.6-ttN` release of this fork receives security fixes.

## Upstream

This is TripTech's fork of [sequinstream/sequin](https://github.com/sequinstream/sequin).
If the issue also affects upstream, please report it to them too. We will
coordinate with them on disclosure where we can.
